# Cómo trabajar en el repositorio

Antes de comenzar, leer `GOAL.md`, `ROADMAP.md`, `STATUS.md` y `AGENTS.md`.
Las features nuevas deben describir qué capacidad dental agregan, qué contrato
consumen del Core y cómo las usará ClínicaDental.

El circuito de scripts ayuda a preparar especificaciones, construir, probar y
revisar cada cambio. No agrega funcionalidades al dominio por sí solo.
