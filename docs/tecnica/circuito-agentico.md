# Circuito de trabajo

El circuito agéntico es infraestructura de desarrollo del repositorio. No es
el producto dental ni define sus reglas de negocio.

Una unidad de trabajo debe tener alcance explícito en `ROADMAP.md`,
 especificación, plan, tareas, revisión, QA, documentación y evidencia
suficiente para su riesgo. Las rutas concretas se generan con los scripts de
`scripts/` y no se rellenan con historial de otros repositorios.

El único punto de decisión humana del flujo normal es MERGE o NO MERGE sobre
una PR con CI verde. El circuito no autoriza modificar Core o ClínicaDental
desde este repositorio.
